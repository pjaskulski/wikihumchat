# wikihumchat
WikiHumChat - prosty czat z bazą wiedzy WikiHum

## Asysta AI / AI Assistance
Kod tej aplikacji został przygotowany przy wsparciu narzędzi sztucznej inteligencji (**OpenAI Codex**). AI zostało wykorzystane do generowania szablonów kodu, autouzupełniania oraz refaktoryzacji, natomiast finalna logika i testy zostały zweryfikowane przez człowieka.
